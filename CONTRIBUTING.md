# Contributing

This project is not accepting external contributions at this time.

Cosignly is developed and maintained by a single developer during a funded sprint. Pull requests from outside the project will be closed without review. You are welcome to:

- Open an issue to report a bug or describe a problem you ran into.
- Fork the project under the terms of the [MIT License](LICENSE).

Security issues must **not** be reported in public issues — see [SECURITY.md](SECURITY.md).
